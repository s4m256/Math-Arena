# Math Arena

Math Arena is a platform for online proof-based math contests.

Users can join competitions, read problems, submit PDF solutions, check standings, and track their rating. The goal is to bring the olympiad experience online while keeping the focus on written mathematical proofs.

Built with Next.js, TypeScript, Supabase, Tailwind CSS, and KaTeX.

Still a work in progress, but the main contest flow is already up and running.
